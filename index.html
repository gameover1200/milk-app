Общая база данных

Общая база уже подключена — партии автоматически видны всем пользователям с любых устройств. Менять эти поля нужно только если вы хотите подключить другую базу.

Как получить эти значения? (пошагово)
  1. Зайдите на supabase.com → New project (нужен email).
  2. Откройте раздел SQL Editor и выполните готовый скрипт создания таблицы (он показан ниже).
  3. В Settings → API Keys скопируйте Project URL и ключ anon (publishable).
  4. Вставьте оба значения в поля выше и нажмите «Подключить».

SQL для создания таблицы (выполнить один раз в SQL Editor):

create table batches (
  id bigint primary key,
  creator_role text,
  created_at text,
  status text,
  kind text,
  supply_date text,
  supplier text,
  product text,
  weight numeric,
  fat numeric, protein numeric, density numeric,
  temperature numeric, somo numeric,
  lab_at text,
  trace jsonb
);
alter table batches enable row level security;
create policy "public access" on batches
  for all using (true) with check (true);
